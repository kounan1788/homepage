# 車検のLINE予約 運用手順書

港南自動車サービスのホームページ（車検ページ https://www.kounan-auto.jp/shaken ）の
受け入れ状況カレンダーから、お客様がLINEで車検予約を申し込めるしくみの使い方です。

---

## 1. しくみ

```
お客様：カレンダーで〇の日を押す →「LINEで予約する」
        → LINEログイン → 予約フォームに入力 →「申し込む」
                                  ↓
                 スプレッドシート「bookings」に1行増える
                 店舗アドレス（kounan.lease@gmail.com）にメールが届く
                                  ↓
お客様：トーク画面が開き、申込文が入力済み → 送信を押す
                                  ↓
お店　：LINE公式アカウントのチャットで返事をして確定
        → シートの「確定日」に日付を入れる
                                  ↓
自動　：確定日の前日17時ごろ、お客様にLINEで前日のお知らせ
```

- 申込の時点では **予約は確定していません**。お客様の画面と申込文にもそう書いてあります。
- 選べるのは **明日以降の〇の日だけ** です。△・×・定休日は選べません（△の日は「お電話でご相談ください」と案内しています）。
- お客様が最後に送信を押し忘れても、**シートとメールには必ず残ります**。
- お店から自動で送るのは前日のお知らせだけです（予約1件につき1通）。毎月の送信件数は月初のレポートメールに出ます。

## 2. 最初の準備（管理者が1回だけ行う）

### 2-1. LINE Developers：予約フォーム用のLIFFアプリを追加する

1. https://developers.line.biz/console/ を開き、車検リマインダーで使っている **LINEログインチャネル** を開く。
2. 「LIFF」タブ →「追加」。
   - LIFFアプリ名：`車検予約`
   - サイズ：**Full**
   - エンドポイントURL：`https://www.kounan-auto.jp/shaken-booking`
   - Scope：`openid` と `profile` にチェック（`chat_message.write` は不要）
   - 友だち追加オプション：**On (Normal)**
3. 作成後に表示される **LIFF ID**（`1234567890-abcdefgh` のような値）を控える。

### 2-2. LINE公式アカウント：ベーシックIDとチャットの確認

1. LINE Official Account Manager を開き、「設定」→「アカウント設定」で **ベーシックID**（`@` から始まるID）を控える。
2. 「設定」→「応答設定」で **チャットがオン** になっていることを確認する（お客様に返事をするため）。

### 2-3. Vercel：環境変数を追加する

「Settings」→「Environment Variables」で次を追加し、再デプロイする。

| Key（名前） | Value（値） | Environments |
|---|---|---|
| `NEXT_PUBLIC_BOOKING_LIFF_ID` | 2-1 の LIFF ID | Production・Preview |
| `NEXT_PUBLIC_LINE_BASIC_ID` | `@131qqwbj`（2-2 のベーシックID。`@` も含める） | Production・Preview |

- `LINE_LOGIN_CHANNEL_ID`・`GAS_WEBHOOK_URL`・`GAS_SHARED_SECRET` は、リマインダーで設定済みのものをそのまま使います（追加不要）。
- この時点ではまだ、カレンダーのボタンは今まで通り友だち追加リンクのままです（公開は 2-6）。

### 2-4. GAS：コードを貼り替える（**設定値を消さないこと**）

GASエディタ（リマインダーのスプレッドシート →「拡張機能」→「Apps Script」）で行います。

1. **貼り替える前に**、今のエディタの次の4行の値をメモ帳に写しておく（本番の値です。人に送らないこと）。
   - `LINE_CHANNEL_ACCESS_TOKEN`
   - `SPREADSHEET_ID`
   - `OWNER_EMAIL`
   - `SHARED_SECRET`
2. `docs/gas/reminder.gs` の中身をすべて貼り付ける。
3. 1 でメモした4つの値を、同じ場所に入れ直す（貼り付けたばかりのファイルでは空欄になっています）。
4. `DRY_RUN` は **今の本番と同じ値** にする（リマインダーが本番で動いているなら `false`）。
5. `BOOKING_DRY_RUN` は **`true` のまま** にする（予約側の試運転）。
6. 保存（💾）する。
7. 「デプロイ」→「デプロイを管理」→ 今のデプロイの ✏️（編集）→ バージョン「新バージョン」→「デプロイ」。
   - **「新しいデプロイ」は使わないこと**（URLが変わり、ホームページの `GAS_WEBHOOK_URL` と合わなくなります）。
8. 1 で値を写したメモは、**保存せずに閉じて削除** する（トークンとシークレットを手元に残さないため）。
9. 初めて申込があって「bookings」シートができたら、**「確定日」の列（J列）** を選び、「表示形式」→「数字」→「日付」にする。年まで表示されるので、年の入れ違いに気づけます。

### 2-5. GAS：前日のお知らせのトリガーを追加する

1. 左メニューの ⏰（トリガー）→「トリガーを追加」。
2. 実行する関数：`bookingDailyCheck`／イベントのソース：時間主導型／タイプ：日付ベースのタイマー／時刻：**午後5時〜6時**。
3. 保存する（初回は承認画面が出るので、管理者アカウントで「許可」）。

> リマインダーの `dailyCheck`（午前9時）と月次の `monthlyUsageReport` のトリガーはそのまま残してください。

### 2-6. 公開前の確認（必ず行う）

**1〜3 は iPhone と Android の両方で行ってください。** この確認が通らないと、申込文がチャットに届かず、予約のしくみが成り立ちません。

1. 公開スイッチはまだ入れず、スマートフォンのLINEで `https://liff.line.me/{LIFF ID}?date={〇の日}`（例 `?date=2026-12-10`）を開く。
   - LINEのトークに貼って開く方法に加えて、**Safari・Chrome のアドレス欄に貼って開く方法** でも試す（お客様はホームページから来るため）。初めての場合はLINEのログイン画面が出て、ログイン後にフォームへ戻り、第1希望に日付が入っていることを確認する。
2. 第1希望にその日が入っていることを確認し、自分の名前で申し込む。
3. 次の3つを確認する。
   - シート「bookings」に1行増え、受付番号（B-0001 など）が入っている
   - 店舗アドレスに「【車検予約の申込】」のメールが届いている
   - 「LINEで申込内容を送信する」でトーク画面が開き、申込文が入力済みになっている → 送信して、チャットに届くことを確認
4. シートのその行の「確定日」に **明日の日付** を入れ、GASエディタで `bookingDailyCheck` を選んで ▶実行。
   - `BOOKING_DRY_RUN = true` なので、お客様（自分）にはLINEが届かず、「【車検予約／DRY_RUN】」の一覧メールが届く
5. `BOOKING_DRY_RUN` を `false` にして保存し、もう一度 ▶実行。
   - 自分のLINEに前日のお知らせが届き、シートの「送信結果」が `OK`、「通知した確定日」が入る
6. もう一度 ▶実行しても **届かない** ことを確認する（同じ確定日に二度は送りません）。
7. 「確定日」に `あした` のような文字や、申込日より前の日付を入れて ▶実行する。お客様には何も送られず「送信結果」も空のまま、店舗には「【車検予約】確定日の確認をお願いします」のメールが届くことを確認する。
8. テストの行は、確定日を消すか行ごと削除する。
9. 2-4 の手順で再デプロイ（新バージョン）しておく（`BOOKING_DRY_RUN = false` を反映するため）。

### 2-7. 公開する

**管理者の承認を得てから** 行ってください。

1. Vercel で `NEXT_PUBLIC_SHAKEN_BOOKING_ENABLED` = `true`（Production）を追加し、再デプロイする。
2. 車検ページのカレンダーで〇の日を押し、「LINEで予約する」が予約フォームに飛ぶことを確認する。

**公開をやめたいとき**：この値を `false` にする（または削除する）→ 再デプロイ。ボタンは友だち追加リンクに戻ります。

## 3. 毎日の操作

### 申込が届いたら

1. 「【車検予約の申込】」のメールが届く。LINE公式アカウントのチャットにも、お客様から申込文（受付番号つき）が届く。
2. チャットで返事をして日程を確定する（第1希望が難しければ第2希望、またはほかの日を提案）。
3. 確定したら、シート「bookings」のその受付番号の行に入力する。
   - **確定日**：確定した日付。**必ず年から入れてください**（例 `2026/12/10`）。`1/8` のように年を省くと今年の日付になり、年をまたぐ予約では前日のお知らせが届きません（その場合は「確定日の確認をお願いします」のメールが毎日届きます）
   - **来店時刻**：必要なら（例 `10:00`）。入れると前日のお知らせに時刻が載ります
4. 確定日の前日17時ごろに、お客様へLINEで前日のお知らせが自動で届く。

### キャンセル・日程変更

- **キャンセル**：確定日を消す（前日のお知らせは送られません）。
- **日程変更**：確定日を新しい日に書き換える。前日のお知らせをすでに送ったあとでも、新しい日の前日にもう一度送られます。

### 気をつけること

- **17時より後に「明日」の予約を確定した場合**、前日のお知らせは自動では届きません。チャットの返事の中でご案内ください。
- **申込文がチャットに届かないお客様**（メールとシートにはあるのに、トークに来ない）には、お電話でご連絡ください。お店からは、お客様がチャットに一度もメッセージを送っていないと返事ができません。
- 前日のお知らせを送れなかった場合は、「【車検予約】前日のお知らせを送れなかったお客様」のメールが届きます。お電話でフォローしてください。
- シートの **1行目（見出し）と列の順番は変えない** でください。列を挿入・入れ替えすると正しく動きません。

```
港南 太郎様
港南自動車サービスです。
明日 12月10日（木） 10:00 は車検のご予約日です。

■ お持ちいただくもの
・車検証
・自賠責保険証明書
・自動車税（種別割）納税証明書（お持ちの場合）
・法定費用(料金はHPを確認して下さい。)
　https://www.kounan-auto.jp/shaken

ご都合が悪くなった場合は、このLINEへのご返信またはお電話でご連絡ください。
■ お電話 076-268-1788（平日 9:00〜18:00 ／ 土曜 9:00〜17:00）
```

- **持ち物の行は、お店のご案内に合わせて直してください。** 文面は `docs/gas/reminder.gs` の `buildBookingReminderMessage_` にあります。直したら 2-4 の手順で再デプロイしてください。
