# 車検受け入れ状況カレンダー 運用手順書

港南自動車サービスのホームページ（車検ページ https://www.kounan-auto.jp/shaken ）に表示される
「車検の受け入れ状況」カレンダーの使い方です。

---

## 1. しくみ

```
Googleスプレッドシート（従業員が〇・△・×を入力）
        ↓ 数分ごとに自動で読み取り（読み取り専用）
ホームページのサーバー
        ↓
車検ページのカレンダー（お客様が見る）
```

- 従業員は **スプレッドシートの〇・△・× を変えるだけ** です。ホームページの操作は不要です。
- 変更がホームページに出るまで **最大3分ほど** かかります（設定で1〜5分に変更可）。
- **memo列（社内メモ）はホームページに一切出ません**。ホームページはA列（date）とB列（status）しか読みません。
- スプレッドシートは一般公開しません。ホームページ専用の「読み取り専用アカウント」だけが中身を読めます。

### ホームページでの表示ルール

| スプレッドシートの入力 | ホームページの表示 |
|---|---|
| 〇 | 〇 受付可能（緑） |
| △ | △ 電話で確認（オレンジ） |
| × | × 受付不可（赤） |
| 空欄・定休日 | 定休日（グレー） |
| 定休日に × | 定休日（グレー） |
| 定休日に 〇・△ | 〇・△（臨時営業として表示） |
| 空欄・営業日 | △ 電話で確認 |

- **スプレッドシートに書いた記号が最優先** です。日曜でも〇を入れれば〇になります。
- 空欄の日が勝手に「〇」になることはありません（安全のため△になります）。
- 定休日は、ホームページに登録した **年間休日表** に載っている日だけです。曜日や祝日からの自動判定はしません。
  年間休日表が未登録の期間は、空欄の日がすべて△（日曜・祝日も）になります。
- 読み取りに失敗したときは、定休日はそのまま、それ以外をすべて△にして「お電話でご確認ください」と表示します。〇は出しません。

## 2. 最初の準備（管理者が1回だけ行う）

### 2-1. スプレッドシートを作る

1. 管理者のGoogleアカウント（kounan.lease@gmail.com など）で Googleドライブを開く。
2. 「新規」→「Googleスプレッドシート」で新しいファイルを作る。名前は「車検受け入れ状況」など。
3. 「ファイル」→「設定」→ **タイムゾーンを「(GMT+09:00) 東京」** にして保存する。
4. 「拡張機能」→「Apps Script」を開く。
5. 最初から書かれている文字をすべて消し、`docs/gas/shaken-calendar.gs` の中身を貼り付けて保存（💾）する。
6. スプレッドシートの画面に戻り、ページを再読み込みする。上のメニューに「車検カレンダー」が出る。
7. 「車検カレンダー」→「シートを準備する（初回のみ）」を押す。
   - 初回は「承認が必要です」と出るので、管理者アカウントを選び「許可」する。
     （「このアプリは確認されていません」と出た場合は「詳細」→「（安全ではないページ）に移動」）
8. 「受け入れ状況」シートができ、今日から3か月先の月末までの日付が並びます。
9. 「車検カレンダー」→「毎月の日付追加を自動にする」を押す（毎月1日に日付が自動で追加されます）。

> シート名「受け入れ状況」と、1行目の見出し（date / status / memo）は変更しないでください。

### 2-2. Google Cloud の設定（読み取り専用アカウントを作る）

1. https://console.cloud.google.com/ を管理者アカウントで開く。
2. 画面上部のプロジェクト選択 →「新しいプロジェクト」→ 名前「kounan-website」などで作成。
3. 左メニュー「APIとサービス」→「ライブラリ」→「Google Sheets API」を検索 →「有効にする」。
4. 「APIとサービス」→「認証情報」→「認証情報を作成」→「サービスアカウント」。
   - 名前：`shaken-calendar-reader`（何でもよい）
   - 「ロール」は **何も付けずに** 「完了」。
5. 作成したサービスアカウントを開き、「キー」タブ →「鍵を追加」→「新しい鍵を作成」→「JSON」→「作成」。
   - JSONファイルがダウンロードされます。**これは合鍵です。メール・LINE・チャットで送らないでください。**
   - 環境変数の設定（2-4）が終わったら、パソコンから削除して構いません（再発行できます）。

費用：Google Sheets API は無料です（クレジットカードの登録も不要）。

### 2-3. スプレッドシートを読み取り専用アカウントに共有する

1. ダウンロードしたJSONファイルをメモ帳で開き、`"client_email"` の値（`...@...iam.gserviceaccount.com`）をコピーする。
2. スプレッドシートの右上「共有」→ そのアドレスを貼り付け → 権限を **「閲覧者」** にする →「通知」のチェックを外して「共有」。
3. 同じ「共有」画面の「一般的なアクセス」が **「制限付き」** になっていることを確認する（「リンクを知っている全員」にしない）。

### 2-4. ホームページ（Vercel）に接続情報を設定する

1. https://vercel.com/ にログインし、ホームページのプロジェクトを開く。
2. 「Settings」→「Environment Variables」で、次の3つを追加する。

| Key（名前） | Value（値） |
|---|---|
| `GOOGLE_SERVICE_ACCOUNT_EMAIL` | JSONの `client_email` の値 |
| `GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY` | JSONの `private_key` の値（`-----BEGIN PRIVATE KEY-----` から `-----END PRIVATE KEY-----\n` まで。途中の `\n` もそのまま） |
| `SHAKEN_SHEET_ID` | スプレッドシートのURL `https://docs.google.com/spreadsheets/d/【ここ】/edit` の【ここ】の部分 |

   - 任意：`SHAKEN_CALENDAR_CACHE_SECONDS`（反映までの秒数。60〜300。既定180）
   - 「Environments」は Production と Preview の両方にチェック。
3. 保存後、「Deployments」→ 最新のデプロイの「…」→「Redeploy」で再デプロイする（設定は再デプロイ後に有効になります）。

### 2-5. 公開前の接続テスト（必ず行う）

公開するまで、車検ページのカレンダー欄は「準備中」と表示されます。お客様には見えない状態のまま、次の確認ができます。

1. 2-4 の再デプロイが終わったら、ブラウザで `https://www.kounan-auto.jp/api/shaken-availability` を開く。
2. 表示された文字の中に `"source":"sheet"` があれば接続成功です。
   - `"source":"error"` の場合は「6. 反映されないとき」を確認。
3. スプレッドシートで適当な日に〇を入れ、3分ほど待ってから 1 のページを再読み込みし、その日付が `"status":"available"` になることを確認する。確認後、テストで入れた〇は元に戻す。
4. （任意）カレンダーの見た目も確かめたい場合は、次の 2-6 の設定を **Preview だけ** にチェックして追加し、Preview デプロイのURLで車検ページを開く。

### 2-6. カレンダーを公開する（準備中を解除する）

接続テストが済み、**管理者の承認を得てから** 行ってください。

1. Vercel の「Settings」→「Environment Variables」で次の1つを追加する（Environments は Production にチェック）。

| Key（名前） | Value（値） |
|---|---|
| `NEXT_PUBLIC_SHAKEN_CALENDAR_ENABLED` | `true` |

2. 「Deployments」→ 最新のデプロイの「…」→「Redeploy」で再デプロイする（2分ほどで公開されます）。
3. 車検ページで「受け入れ状況カレンダーを見る」ボタンが出ていれば公開完了です。

**準備中に戻したいとき**：この設定の Value を `false` に変える（または削除する）→ 再デプロイ。

## 3. 毎日の操作（受け入れ状況を変える）

### パソコンの場合

1. スプレッドシート「受け入れ状況」シートを開く。
2. 変えたい日付の行の **status（B列）** をクリックし、▼から〇・△・× を選ぶ。
3. 必要なら memo（C列）に社内向けのメモを書く（ホームページには出ません）。
4. 保存ボタンはありません。自動で保存され、数分でホームページに反映されます。

### スマートフォンの場合

1. 「Googleスプレッドシート」アプリ（iPhone/Android）を入れ、管理者から共有されたアカウントでログインする。
2. ファイルを開き、status のマスをタップ → もう一度タップすると〇・△・× の選択肢が出るので選ぶ。
3. 右上の ✓ を押して完了。

> スマートフォンのアプリでは「車検カレンダー」メニューは出ません。日付の追加や入力チェックはパソコンで行ってください（毎月の日付追加は自動にしてあれば不要です）。

### 記号の目安

- **〇**：車検を受け入れられる見込みがある日
- **△**：受け入れられる可能性はあるが、確認が必要な日
- **×**：受け入れできない日（予約がいっぱい・臨時休業など）
- **空欄**：未定。ホームページでは△（定休日は×）になります

---

## 4. 臨時休業日・臨時営業日の登録

- **臨時休業**（平日だけど休む）：その日の status を **×** にする。memo に「臨時休業」などと書いておくと後で分かりやすいです。
- **臨時営業**（定休日だけど受け付ける）：その日の status を **〇** または **△** にする。シートの記号が定休日より優先されます。
- 年間の定休日そのもの（日曜・土曜・祝日・年末年始・お盆など）は、ホームページ側の年間休日表（`lib/businessDays.ts`）で管理しています。
- **翌年度（4月〜翌3月）の年間休日表は、前年の12月中にホームページの担当者へ提出してください。**
  カレンダーは3か月先まで表示するため、1月には4月分が見え始めます。登録が間に合わないと、その期間の日曜・祝日も△で表示されます。

---

## 5. 日付の追加・入力チェック

- 「車検カレンダー」→「日付を追加する」：今日から3か月先の月末まで、足りない日付を追加して日付順に並べ直します。
- 「車検カレンダー」→「入力ミス・重複を確認する」：同じ日付が2行ある・記号が違う、などを一覧で知らせます。
- 同じ日付が2行あると、日付のマスが赤くなります。どちらか1行を削除してください。
  （そのままでもホームページは壊れません。厳しい方＝× → △ → 〇 の順で表示されます）

---

## 6. ホームページに反映されないとき

上から順に確認してください。

1. **3〜5分待ったか**：反映まで最大3分（設定による）かかります。ページを再読み込みしてください。
2. **シート名が「受け入れ状況」のままか**、1行目が見出し（date / status / memo）か、データが2行目から始まっているか。
3. **日付がA列、記号がB列にあるか**。列を挿入・入れ替えしていないか。
4. **記号が 〇・△・× か**。「入力ミス・重複を確認する」を実行して確認。
5. **共有が外れていないか**：「共有」画面に読み取り専用アカウント（`...iam.gserviceaccount.com`）が「閲覧者」で残っているか。
6. `https://www.kounan-auto.jp/api/shaken-availability` を開いて確認：
   - `"source":"sheet"` → 接続は正常。1〜4を再確認。
   - `"source":"error"` → 接続できていません。5を確認し、Vercel の環境変数（2-4）が正しいか、再デプロイしたかを確認。
     Vercel の「Logs」に `[shaken-availability]` で始まる原因が出ています。
7. カレンダーに「表示中の情報は ○時点のものです」と出ている：一時的に読み取りに失敗し、前回の内容を表示しています。6を確認してください。

---

## 7. 権限の管理

- スプレッドシートの編集権限は、**管理者と担当の従業員だけ** に「編集者」で付けてください。
- 退職・異動した人は「共有」から削除してください。
- 「リンクを知っている全員」への公開は絶対にしないでください。
- 読み取り専用アカウントの権限は「閲覧者」のままにしてください（ホームページ側も読み取り専用の設定です）。

## 8. JSONの鍵をなくした・漏れたかもしれないとき

1. Google Cloud の「サービスアカウント」→「キー」タブで、古い鍵を **削除** する（これで古い鍵は使えなくなります）。
2. 新しい鍵を作成し、2-4 の `GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY` を新しい値に置き換えて再デプロイする。

## 付録：技術メモ（ホームページ担当者向け）

| 項目 | 場所 |
|---|---|
| 表示期間（当月＋3か月）・古さの判定（30分） | `lib/shakenCalendar/config.ts` |
| ステータスの決定・不正データの扱い | `lib/shakenCalendar/availability.ts` |
| 定休日の判定（年間休日表に載っている日だけ） | `lib/shakenCalendar/closedDays.ts` |
| 年間休日表（新年度分は `CLOSED_DATES` に追加） | `lib/businessDays.ts` |
| Google Sheets API の読み取り | `lib/shakenCalendar/sheetsClient.ts` |
| 公開API | `app/api/shaken-availability/route.ts` |
| カレンダー画面 | `components/ShakenAvailabilityCalendar.tsx` |
| 電話番号・LINE URL | `lib/chatFlow.ts` の `TEL` / `LINE_URL` |
| 自動テスト | `npm test` |

- ローカル開発でカレンダーを表示するには、`.env.local` に `NEXT_PUBLIC_SHAKEN_CALENDAR_ENABLED=true` を書いて `npm run dev` を起動し直す（無ければ「準備中」表示）。
- ローカル開発（`npm run dev`）で接続情報が未設定のときは、ダミーデータと「開発用のダミーデータを表示しています」の表示が出ます。本番では出ません。
- 「最終更新」は、ホームページがスプレッドシートを最後に読み取った日時です。
